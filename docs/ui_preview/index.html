为什么"不幼稚" Visual Language

  • 去掉表情符号：面板标题改用线性图标 + 中英双标签（中文主标签 + 9.5px 等宽大写英文副标签），这是仪器类软件的语言，不是消费级产品的语言。
  • 圆角收紧到 3–6px，取消大阴影，改用 1px 细线分隔 —— 边界靠线而不是靠投影。
  • 颜色只给数据：界面本身只用中性灰阶 + 一个强调色；彩色面积只出现在图件、状态点和优先级标签上。
  • 信息密度提高：14 行参数表、遥测行、管道进度条同屏可见，符合工程师"一屏看全"的习惯。
  • 数字全部等宽 + 表格数字对齐（tabular-nums），坐标、浓度、时长可以竖向比对。

落地方式 Gradio 6.18

  • gr.Blocks(css=…, theme=gr.themes.Base()) —— 已在本机实测：自定义 CSS 确实注入进页面（起了临时服务抓页面验证），css / theme / head 在 6.18 仍可通过 kwargs 传入。
  • 主题令牌全部写成 CSS 变量，一套变量同时喂 gr.themes.Base().set(...) 和自定义 CSS，避免两套色值漂移。
  • 组件原生能力优先：variant="primary"、size="sm"、gr.Accordion、gr.Tabs、gr.Dataframe，只在样式上覆盖。
  • 图件侧同步换字体与配色（matplotlib rcParams + 同一套色值），否则界面精致而图件仍是默认样式，会更显割裂。

需要你定夺的三处 Open Choices

  • 中文/英文标签：现在每个面板是"中文 + 等宽英文副标签"。若嫌英文多余，可只留中文（去掉 .hd-en 即可，不影响布局）。
  • 默认主题：浅色更接近论文/报告印象，深色更像专业软件。建议默认浅色，深色作为可切换项保留 —— 请指定。
  • 对话区样式：现在设计成"角色标签 + 平铺内容"（无气泡）。这需要覆盖 Gradio Chatbot 的 .message 类；若覆盖不稳，退化为方角气泡（视觉略降但实现稳）。

刻意没改的东西 Unchanged

  • 模块与控件结构一字未动：对话、参数表、IR 审查、代码预览、六个结果页签、调试日志、快速开始，位置与层级都保持原样，改动只发生在样式层。
  • 不改任何文案的含义：只把"💡 快速开始"这类标题里的表情符号换成线性图标，文字内容照旧。
  • 不改事件接线：上一轮的「确定重绘」等交互逻辑不受本次美化影响。
